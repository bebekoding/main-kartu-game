# Profile avatar asset

Generated with the built-in Imagegen tool on 2026-11-02.

Final project asset: `assets/avatars/anime-emblems-v1.png`.
One transparent RGBA PNG, 1254 by 1254 pixels, 1,576,704 bytes. The 16
fixed IDs in `player-profiles.js` match a four-column, four-row atlas.
CSS selects a cell; the generated artwork is not cropped or redrawn.
The original generated file remains in the agent generated-images folder.

The attached Naruto, One Piece and Attack on Titan images were visual
references for the user's intended emblem-style avatars. They were not
uploaded into the game, and their labels/watermarks are not used.
